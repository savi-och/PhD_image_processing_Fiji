# PhD_image_processing_Fiji
Macros established and used for confocal and timelapse recording processing

Relevant:

save_bioformat_images / save_sld_bioformat_images --> save raw images (in batch)

reassignchannels_andscalebar_comp --> reassign channel colours and add scale bar (in batch)

max_project --> create maximum intensity projections (in batch)

save_adjusted_pictures / save_images_jpg_png  --> save processed images

ApplyLUT_Cal --> Apply Fire LUT map and calibration bars for Hoechst perfused explants

MultiStackReg_batch_Correct_version --> image drift correction via MultiStackReg

Estimating_infected_gfp_area --> estimation of oHSV_GFP positive area
